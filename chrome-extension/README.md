# 🌐 STL-Manager Tracker – Chrome / Chromium Extension

This extension captures the original webpage URL whenever you download 3D models from sites like **MakerWorld**, **Printables**, **Thingiverse**, **Cults 3D**, **MakerOnline**, and **Creality Cloud**, and automatically attaches the source URL to the model in your local **STL-Manager**.

---

## 🚀 Installation in Google Chrome / Brave / Microsoft Edge / Opera

1. Open your browser and navigate to:
   ```text
   chrome://extensions
   ```
   *(or `edge://extensions` in Edge, `brave://extensions` in Brave)*
2. Enable **Developer mode** using the toggle switch in the top-right corner.
3. Click the **"Load unpacked"** button (top-left).
4. Select the `chrome-extension` folder inside your `STL-Manager` project directory.
5. Done! The extension is active and will automatically record the model source webpage when you download STL or 3MF files.
