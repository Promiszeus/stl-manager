# STL-Manager Tracker – Firefox Add-on

Dieses Add-on erfasst automatisch die Webseiten-Quell-URL beim Herunterladen von 3D-Modellen (MakerWorld, Printables, Thingiverse, Cults3D etc.) und überträgt sie direkt an deinen lokalen **STL-Manager**.

---

## 🦊 Installation in Mozilla Firefox

1. Öffne Firefox und tippe in die Adresszeile:
   ```text
   about:debugging#/runtime/this-firefox
   ```
2. Klicke auf die Schaltfläche **„Temporäres Add-on laden...“** (Load Temporary Add-on).
3. Wähle die Datei `manifest.json` im Ordner `firefox-extension/` aus.
4. Fertig! Das Add-on ist aktiv und fängt Downloads von 3D-Modellen automatisch ab.
